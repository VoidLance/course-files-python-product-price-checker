# Product Price Checker

A small Python example that compares the prices of a Hoop coffee filter and a Barista espresso machine, then prints which product costs more.

## Why use it?

- Demonstrates variables and `if`/`elif`/`else` comparisons in Python.
- Prints a clear result when one product is cheaper, more expensive, or the two prices are equal.
- Runs with Python 3 and has no external dependencies.

## Getting started

Make sure Python 3 is installed, then run the script from the project directory:

```bash
python3 "Product Price Checker.py"
```

The current prices are set near the top of the script. Edit `hoop` and `barista` to compare different prices. With the values in the repository, the output is:

```text
Hoop is less expensive than barista
```
